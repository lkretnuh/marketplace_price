# Поиск через браузер

Основной режим теперь работает через расширение в существующем окне Chrome — [EXTENSION.md](EXTENSION.md). Там Playwright не нужен. Ниже описан запасной режим **«Отдельный Chromium»**: выберите его в поле «Браузер» в Ценоскопе.

## Установка

На Windows запустите `setup-search-windows.bat`. Он установит Playwright и Chromium для Python 3.14. Затем запускайте `start-windows.bat` и открывайте http://localhost:8000.

На macOS/Linux используйте один и тот же Python для установки и запуска:

```sh
python3 -m pip install -r requirements-search.txt
python3 -m playwright install chromium
python3 app.py
```

В Linux также могут потребоваться системные библиотеки из официальной инструкции Playwright. Нужна графическая сессия для видимого браузера.

## Как искать

1. Введите `Kiwi Ears Orchestra Lite` в верхнее поле «Найти товар на маркетплейсах» и нажмите «Найти карточки». Товар появится в списке автоматически. Повторный запрос того же названия использует существующий товар; старые дубли не удаляются автоматически.
2. Откроется отдельный Chromium с вкладками четырёх площадок. Выберите Санкт-Петербург на каждой площадке. Приложение не задаёт регион и не обходит CAPTCHA. Если проверка или вход нужны, выполните их самостоятельно в этом окне.
3. Карточки прочитанных страниц появятся в приложении. Каждые 8 секунд читается DOM, без перезагрузок сайта. Можно нажать «Прочитать открытые вкладки». Прокрутка вкладки может подгрузить дополнительные карточки. Собираются до 60 загруженных карточек с каждой страницы, а не весь каталог.
4. Проверьте модель и вариант товара. Поисковая выдача может содержать аксессуары, рекламу и похожие модели.
5. Нажмите «Добавить в сравнение». Ссылка и прочитанная цена подставляются в форму. Проверьте продавца, валюту, скидки, способ оплаты и доставку для своего города. Неизвестные поля оставлены пустыми. До подтверждения результат не считается наблюдением цены.

Выдача сохраняется в памяти до следующего поиска или перезапуска сервера. Подтверждённые наблюдения хранятся в SQLite. Окно поиска закрывается кнопкой в приложении или автоматически через 15 минут. Одновременно работает одна сессия поиска; её можно восстановить в интерфейсе после обновления страницы.

## Статусы и ограничения

- «Получены карточки»: прочитаны ссылки и названия с открытой страницы; цена и доставка могут отсутствовать.
- «Проверка доступа или вход»: нужна ручная работа в видимой вкладке.
- «Ничего не найдено»: сайт явно сообщил о пустой выдаче.
- «Карточки не прочитаны»: загрузка, ограничения доступа или неподдерживаемая разметка. Это **не подтверждает отсутствие товара**.
- «Вкладка закрыта» / ошибка чтения: проверьте окно поиска или запустите новую сессию.

Чтение зависит от текущей разметки сайтов. Проверка реальных площадок из облачной среды пока заблокирована её сетевой политикой. Тесты на локальных HTML-страницах подтверждают работу механизма, но не гарантируют результаты реального поиска. Не реализованы скрытый сбор, обход защиты, автоматическое обновление истории по расписанию и гарантированная полнота каталога.

Профиль `data/browser-profile/` отдельный от основного Chrome. Он может содержать ваши cookies, если вы вошли на сайт: не публикуйте его и не добавляйте в Git. Не запускайте два сервера с одним профилем. Код не читает файлы cookies и не выгружает сессии.

Браузерные проверки: `python3 scripts/browser_smoke.py`. В них сетевые обращения страниц перехватываются локальными HTML-ответами; живые цены не используются.
