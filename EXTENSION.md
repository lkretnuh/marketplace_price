# Ваше окно Chrome: установка и сбор данных

## Один раз на каждом устройстве

1. Распакуйте приложение в постоянную папку. Запустите `start-windows.bat` (Python 3.14) и откройте http://localhost:8000 в том окне Chrome, где хотите работать.
2. В адресную строку Chrome вставьте `chrome://extensions`.
3. Включите **«Режим разработчика»** в правом верхнем углу.
4. Нажмите **«Загрузить распакованное расширение»** и выберите папку **`chrome-extension`** внутри приложения. Выбирайте папку с `manifest.json`, а не ZIP или родительскую папку.
5. Разрешите доступ к четырём площадкам и localhost. Для периодического чтения подключённых вкладок разрешения должны действовать на этих сайтах, а не только по нажатию. Cookies, пароли и история браузера не запрашиваются.
6. Вернитесь в Ценоскоп, нажмите **Ctrl+F5**. Должно появиться **«Расширение подключено»**. Выберите режим **«Моё окно Chrome (расширение)»**.

Playwright и отдельный Chromium в этом режиме **не нужны**. `setup-search-windows.bat` нужен только для запасного режима «Отдельный Chromium».

## Поиск и открытие карточек

Введите название и нажмите «Найти карточки». Четыре вкладки откроются **в том же окне**, где находится Ценоскоп, с вашими настройками сайтов. Расширение не запускает другой профиль и не копирует сессии. Выберите Санкт-Петербург на площадках. Проверки доступа и вход выполняются вручную.

Нажмите **«Открыть и собрать»** в результатах. Карточка откроется в этом окне и подключится к сбору. Если такая же ссылка уже открыта в этом же окне, используется существующая вкладка. Вкладка другого окна не перетаскивается. Кнопка ↗ у сохранённого предложения тоже открывает карточку и подключает её к сбору.

Чтобы подключить произвольную уже открытую вкладку:

1. Сначала запустите один поиск в Ценоскопе в этом же окне.
2. Откройте нужную вкладку маркетплейса.
3. Нажмите значок расширения (его можно закрепить через кнопку пазла Chrome).
4. Нажмите **«Собирать из этой вкладки»**. Её карточки относятся к текущему товару Ценоскопа: проверьте модель перед сохранением.

По умолчанию данные читаются примерно каждые 8 секунд, без перезагрузки страниц. Браузер может замедлять фоновые вкладки; для немедленного чтения есть «Прочитать открытые вкладки». Сбор включён только в подключённых вкладках. **«Остановить сбор» оставляет вкладки открытыми**. Закрытие вкладки Ценоскопа отключает её сбор. Для другого товара сначала остановите текущий сбор. После перезапуска Chrome или сервера начните новый поиск.

## Значения и история

Читаются название, ссылка, показанная цена в рублях, продавец, текст доставки и отдельные рейтинги товара/продавца, если их удалось определить. На странице самого товара данных часто больше, чем в выдаче. Расширение не обращается к закрытым API и не обходит CAPTCHA.

Сроки распознаются из явного диапазона дней, «сегодня/завтра/послезавтра» и поддерживаемых дат с месяцем. Бесплатная доставка учитывается только при явном указании. Проценты положительных отзывов не пересчитываются в звёзды. Неизвестные значения остаются пустыми.

«Добавить в сравнение» открывает форму с прочитанными значениями. Проверьте город, комплектацию, оплату, скидки и доставку. Только после подтверждения наблюдение попадает в SQLite и на график. Повторное сохранение той же карточки в этом товаре добавляет наблюдение к истории, не создавая дубликат предложения. Рейтинги хранятся в каждом наблюдении; у старых записей они неизвестны.

## Сортировка

Сортировка работает отдельно над найденными карточками и сохранёнными предложениями:

- цена товара по возрастанию / убыванию;
- цена с доставкой по возрастанию / убыванию;
- срок доставки — сначала меньшая верхняя граница диапазона;
- рейтинг товара — сначала выше;
- рейтинг продавца — сначала выше.

Рейтинги сравниваются по шкале **0–5**. Неизвестные значения всегда в конце. Для полной цены нужна известная стоимость доставки: неизвестная не считается бесплатной. В сохранённых предложениях используются последние наблюдения выбранного города. Похожие модели и комплектации автоматически не объединяются.

## Обновление и ограничения

Остановите сервер, сделайте резервную копию `data/`, замените файлы в прежней папке, оставив `data/`. На `chrome://extensions` нажмите кнопку обновления расширения, перезапустите приложение и нажмите Ctrl+F5 на его странице. При перемещении папки загрузите расширение из нового пути и удалите старую копию расширения.

Если Chrome управляется организацией и запрещает распакованные расширения, нужен доступ администратора. В облачном браузере разработки такой запрет действует: реальная установка расширения там не прошла. Проверены обработчики Chrome API с тестовой заменой и настоящий DOM-сборщик/мост/интерфейс с тестовым транспортом. Для отдельной проверки на обычном Chromium предоставлен `scripts/extension_smoke.py`.

Текущая совместимость с живой разметкой четырёх площадок из облака не подтверждена из-за сетевых ограничений. Ошибка чтения/доступа не означает отсутствие товара. Полнота каталога не гарантируется; автоматического фонового сохранения истории пока нет.
