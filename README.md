# Ценоскоп

Локальное приложение для сравнения предложений Ozon, Wildberries, Яндекс Маркета и AliExpress. На Windows используйте Python 3.14. Основной режим — расширение для вашего Chrome, без Playwright и отдельного окна: [EXTENSION.md](EXTENSION.md). Запасной режим отдельного Chromium — [SEARCH.md](SEARCH.md).

## Запуск

Скачайте ZIP через **Code → Download ZIP** на GitHub, распакуйте его и откройте терминал в папке с `app.py`.

```sh
python3 app.py
```

На Windows запустите `start-windows.bat` или `py -3.14 app.py`, затем откройте **http://localhost:8000** в своём Chrome. Загрузите папку `chrome-extension` через `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное расширение». Обновите Ценоскоп через Ctrl+F5. Инструкция — `START_HERE.txt` и [EXTENSION.md](EXTENSION.md). Установщик `setup-search-windows.bat` нужен только для отдельного Chromium.

При обновлении остановите сервер (`Ctrl+C`), сохраните копию `data/`, замените файлы приложения, оставив `data/` рядом с `app.py`. Перезагрузите расширение на `chrome://extensions`, запустите сервер и нажмите `Ctrl+F5` на странице приложения. База совместима: поля рейтингов добавляются автоматически, старая история не удаляется.

В локальном окружении откройте порт 8000 в браузере. По умолчанию сервер слушает только 127.0.0.1. Облачная среда может не предоставлять доступ к локальному интерфейсу. Параметры: `--host`, `--port`, `--db`. Не публикуйте сервер в интернете: эта версия рассчитана на одного доверенного пользователя, без авторизации и production-сервера.

База создаётся автоматически в `data/prices.sqlite3` (или `PRICE_DB`). Исходно она пустая. Демо включается отдельной кнопкой, явно помечено и доступно только для просмотра; его можно удалить. Реальные товары и демоданные не смешиваются внутри одного товара.

## Что работает

- Группы товаров по названию, модели и комплектации.
- Поиск и открытие карточек в существующем окне Chrome через расширение. Подключение уже открытой вкладки через значок расширения; остановка сбора не закрывает вкладки. Отдельный Chromium доступен как запасной режим.
- Добавление карточек по HTTPS-ссылкам; несколько продавцов/карточек одной площадки видны отдельными строками.
- Сбор названия, цены, доставки и отдельных рейтингов товара/продавца из подключённых страниц. Прочитанные значения подставляются в форму; пользователь подтверждает условия и сохранение. Санкт-Петербург и RUB по умолчанию.
- Неизменяемая история наблюдений с временем записи (отображение по Москве), график за 7/30 дней и всё время, точные значения в журнале.
- Сортировка найденных и сохранённых предложений по цене товара, цене с доставкой, верхней границе срока доставки и двум рейтингам (0–5). Неизвестные значения всегда в конце. Фильтры города и площадки; истории разных городов не объединяются.
- SQLite сохраняет данные между перезапусками. Суммы хранятся целыми копейками.

Сроки доставки — оценка, введённая на момент наблюдения, а не актуальный обещанный срок площадки. Сравнивайте одну комплектацию и одинаковые условия оплаты; автоматической проверки эквивалентности нет. При отсутствии наблюдения для города предложение не участвует в сравнении. Фильтр периода относится к графику; таблица показывает последнее наблюдение выбранного города.

## Пока не реализовано

Автоматическое расписание обновления истории, уведомления, проверка наличия, конвертация валют, экспорт и аккаунты. Поиск читает загруженную браузером выдачу, а не полный каталог. История пополняется после подтверждения цены и доставки пользователем. При ручном добавлении ссылки её содержимое не загружается. Результаты сравнения могут устареть.

Для надёжного фонового сбора без открытого браузера нужен проверенный источник данных для каждой площадки: официальный API/партнёрский фид либо поставщик данных с нужными правами. API продавца нельзя заранее считать источником всего потребительского каталога. CAPTCHA не обходится; доступность сайтов не гарантируется. Ключи для текущей версии не нужны.

Для сопоставления обязательно учитывать модель, цвет, размер, комплект, состояние и валюту. До подтверждения пользователем предложения остаются отдельными карточками.

## Проверки

```sh
python3 -m unittest discover -s tests -v
node --check web/app.js
node --check chrome-extension/extract.js
node tests/comparison.test.cjs
node tests/extension.test.cjs
```

Проверяются API, копейки, миграция базы, история рейтингов, города, ошибки, удаление и приём данных расширения. Тесты используют временные базы. Браузерные проверки: `python3 scripts/browser_smoke.py` (отдельный Chromium) и `python3 scripts/extension_harness_smoke.py` (настоящий DOM/мост/интерфейс с тестовой заменой Chrome-транспорта). `TEST_CHROMIUM` задаёт путь к системному Chromium. `scripts/extension_smoke.py` предназначен для настоящего расширения в браузере, где его установка разрешена; в облаке она заблокирована административной политикой. Обработчики Chrome API проверены тестовыми заменами. Живые маркетплейсы из облака недоступны по сетевой политике: совместимость с текущей разметкой не подтверждена.

Для резервной копии остановите приложение и скопируйте весь каталог `data/`. Во время работы используйте SQLite backup API, а не копирование одного файла открытой WAL-базы.
