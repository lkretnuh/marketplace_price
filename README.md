# Ценоскоп

Локальное веб-приложение для сравнения предложений Ozon, Wildberries, Яндекс Маркета и AliExpress. Для ручного учёта достаточно Python 3.12+ и SQLite. Для поиска нужен Playwright; на Windows используйте Python 3.14. Установка и ограничения поиска — [SEARCH.md](SEARCH.md).

## Запуск

Скачайте ZIP через **Code → Download ZIP** на GitHub, распакуйте его и откройте терминал в папке с `app.py`.

```sh
python3 app.py
```

На Windows один раз запустите `setup-search-windows.bat`, затем запускайте `start-windows.bat` или `py -3.14 app.py`. Оба скрипта используют Python 3.14, независимо от старой версии в PATH. Затем откройте **http://localhost:8000** в обычном браузере. Подробная инструкция — `START_HERE.txt`.

При обновлении остановите сервер (`Ctrl+C`), сохраните копию папки `data/`, замените файлы приложения, оставив свою `data/` рядом с `app.py`. Установите модуль поиска, запустите сервер и обновите страницу через `Ctrl+F5`. Существующая база совместима, история не удаляется.

В локальном окружении откройте порт 8000 в браузере. По умолчанию сервер слушает только 127.0.0.1. Облачная среда может не предоставлять доступ к локальному интерфейсу. Параметры: `--host`, `--port`, `--db`. Не публикуйте сервер в интернете: эта версия рассчитана на одного доверенного пользователя, без авторизации и production-сервера.

База создаётся автоматически в `data/prices.sqlite3` (или `PRICE_DB`). Исходно она пустая. Демо включается отдельной кнопкой, явно помечено и доступно только для просмотра; его можно удалить. Реальные товары и демоданные не смешиваются внутри одного товара.

## Что работает

- Группы товаров по названию, модели и комплектации.
- Поиск через отдельный видимый браузер: прочитанные карточки показываются в приложении, статус каждой площадки — отдельно. Прямые ссылки на поиск также сохранены.
- Добавление карточек по HTTPS-ссылкам; несколько продавцов/карточек одной площадки видны отдельными строками.
- Ручные наблюдения: цена, доставка, диапазон дней получения, город, условия оплаты и скидок. Санкт-Петербург и RUB по умолчанию.
- Неизменяемая история наблюдений с временем записи (отображение по Москве), график за 7/30 дней и всё время, точные значения в журнале.
- Сравнение итоговой цены с доставкой и сортировка по максимальному сроку доставки, фильтры города и площадки. Истории разных городов не объединяются.
- SQLite сохраняет данные между перезапусками. Суммы хранятся целыми копейками.

Сроки доставки — оценка, введённая на момент наблюдения, а не актуальный обещанный срок площадки. Сравнивайте одну комплектацию и одинаковые условия оплаты; автоматической проверки эквивалентности нет. При отсутствии наблюдения для города предложение не участвует в сравнении. Фильтр периода относится к графику; таблица показывает последнее наблюдение выбранного города.

## Пока не реализовано

Автоматическое расписание обновления истории, уведомления, проверка наличия, конвертация валют, экспорт и аккаунты. Поиск читает загруженную браузером выдачу, а не полный каталог. История пополняется после подтверждения цены и доставки пользователем. При ручном добавлении ссылки её содержимое не загружается. Результаты сравнения могут устареть.

Для надёжного фонового сбора без открытого браузера нужен проверенный источник данных для каждой площадки: официальный API/партнёрский фид либо поставщик данных с нужными правами. API продавца нельзя заранее считать источником всего потребительского каталога. CAPTCHA не обходится; доступность сайтов не гарантируется. Ключи для текущей версии не нужны.

Для сопоставления обязательно учитывать модель, цвет, размер, комплект, состояние и валюту. До подтверждения пользователем предложения остаются отдельными карточками.

## Проверки

```sh
python3 -m unittest discover -s tests -v
node --check web/app.js
node --check search_extract.js
```

Тесты проверяют HTTP-сценарий, историю, копейки, города, ошибки, удаление, ограничения демо, повторные запросы и статусы поиска. Тесты используют временные базы. Отдельный браузерный тест: `python3 scripts/browser_smoke.py` (при необходимости `TEST_CHROMIUM` — путь к системному Chromium). Он проверяет сборщик, API и интерфейс на локальных HTML-страницах. Проверка живых маркетплейсов в облаке заблокирована сетевой политикой; совместимость с их текущей разметкой пока не подтверждена.

Для резервной копии остановите приложение и скопируйте весь каталог `data/`. Во время работы используйте SQLite backup API, а не копирование одного файла открытой WAL-базы.
