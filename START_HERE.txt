ЦЕНОСКОП — быстрый запуск

1. Установите Python 3.12 или новее: https://www.python.org/downloads/
   На Windows включите «Add python.exe to PATH» при установке.
2. Распакуйте архив целиком. Не запускайте файлы прямо из ZIP.
3. Windows: откройте start-windows.bat.
   macOS / Linux: в терминале в папке приложения выполните:
   python3 app.py
4. Откройте в браузере: http://localhost:8000

Не закрывайте терминал, пока используете приложение.
Остановка: Ctrl+C. Повторный запуск — тем же способом.
Если порт занят: python app.py --port 8001 (на macOS/Linux — python3),
затем откройте http://localhost:8001.

История сохраняется в data/prices.sqlite3 рядом с приложением.
Не удаляйте папку data. В архив не включена база из облачной среды:
после первого запуска будет создана новая пустая база.
Для знакомства нажмите «Посмотреть демо» в приложении.

В этой версии цены вводятся вручную. Автоматический сбор и единый
поиск по маркетплейсам ещё не подключены. Приложение даёт переходы
к поиску на сайтах площадок. Город: Санкт-Петербург, валюта: рубли.
Сторонние Python-библиотеки устанавливать не нужно.
Приложение локальное, без учётных записей; не публикуйте его в интернете.
